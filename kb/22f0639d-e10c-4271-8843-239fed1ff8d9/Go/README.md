# Go

## 1. 并发编程模型（Goroutines 与 Channels）
*   **核心概念**：Goroutine 是轻量级用户态线程，由 Go 运行时调度；Channel 是类型安全、用于 goroutine 间通信和同步的管道。
*   **关键原理**：GMP调度模型（Goroutine、Machine、Processor）。Select 语句用于多路复用 channel 操作。
*   **面试考点**：
    *   Goroutine 的创建、调度与退出（goroutine 泄漏）。
    *   Channel 的有缓冲/无缓冲区别、方向（只读/只写）、关闭操作。
    *   并发模式：Fan-in/Fan-out， Worker Pool， Pipeline。
    *   如何避免数据竞争？（`sync.Mutex`, `sync.RWMutex`, atomic 操作）。
    *   `sync.WaitGroup` 和 `context` 的典型用法。

## 2. 内存管理与垃圾回收 (GC)
*   **核心概念**：Go 使用自动内存管理，由 GC 负责回收不再使用的堆内存。
*   **关键原理**：三色标记清除算法（并发标记，混合写屏障）。GC 分为多个阶段，目标是低延迟。
*   **面试考点**：
    *   栈内存与堆内存的区别，何时变量会逃逸到堆上？（逃逸分析）。
    *   GC 如何触发？GOGC 参数的作用。
    *   `sync.Pool` 的作用与适用场景（对象复用，减少GC压力）。
    *   常见内存泄漏场景：goroutine 泄漏、未关闭的资源（如数据库连接）、全局缓存。

## 3. 错误处理机制
*   **核心概念**：Go 使用明确的返回值（通常为 `error` 类型）来处理错误，而非异常。
*   **关键原理**：`error` 是接口类型。推荐使用 `fmt.Errorf` 和 `%w` 进行错误包装。
*   **面试考点**：
    *   如何创建、检查和比较错误？（`errors.Is`, `errors.As`）。
    *   错误处理最佳实践：清晰返回、逐层包装、提供上下文。
    *   `panic` 和 `recover` 的使用场景与限制（通常用于不可恢复的严重错误或库的初始化失败）。
    *   如何设计自定义错误类型？

## 4. 类型系统（接口与结构体）
*   **核心概念**：接口是隐式实现的（鸭子类型）。结构体是组合的基础，通过嵌入（Embedding）实现继承效果。
*   **关键原理**：接口值包含类型和值两个部分。结构体嵌入会提升被嵌入字段的方法。
*   **面试考点**：
    *   接口的底层表示（`iface` 与 `eface`）。
    *   空接口 `interface{}` 或 `any` 的用途与类型断言。
    *   结构体嵌入与方法提升、冲突解决。
    *   值接收者与指针接收者的区别和选择原则。

## 5. 测试与基准测试
*   **核心概念**：Go 内置了强大的 `testing` 包。单元测试文件以 `_test.go` 结尾。
*   **关键原理**：`func TestXxx(t *testing.T)` 为单元测试；`func BenchmarkXxx(b *testing.B)` 为基准测试。
*   **面试考点**：
    *   表驱动测试（Table-driven tests）的写法与优势。
    *   如何使用 `t.Run` 运行子测试和 `b.ResetTimer` 消除基准测试中的初始化开销。
    *   Testify 等第三方测试库的使用。
    *   如何测试并发代码？（竞态检测 `-race`）。

## 6. 反射 (Reflection)
*   **核心概念**：`reflect` 包允许在运行时检查和操作变量的类型和值。
*   **关键原理**：`reflect.Type` 和 `reflect.Value` 是两个核心类型。
*   **面试考点**：
    *   反射的三大法则：从接口值到反射对象、从反射对象到接口值、修改反射对象。
    *   反射的性能开销及使用建议（谨慎使用，主要在序列化、ORM等库中使用）。
    *   如何通过反射遍历结构体字段、调用方法。

## 7. 包管理与工具链
*   **核心概念**：Go Modules 是官方的依赖管理系统（`go.mod`, `go.sum`）。`go` 命令集成了构建、测试、格式化等多种工具。
*   **关键原理**：语义化版本控制。模块代理和校验和数据库保证下载安全。
*   **面试考点**：
    *   `go mod init`, `go get`, `go mod tidy` 等命令的作用。
    *   `go build`, `go test`, `go run`, `go fmt`, `go vet` 的用途。
    *   内部包（internal package）的作用。

## 8. 错误处理模式与最佳实践
*   **核心概念**：早期返回（Guard Clause）模式是 Go 中处理错误的标准范式。
*   **关键原理**：避免嵌套，使代码清晰。错误应被有意义地处理，而不是被忽略。
*   **面试考点**：
    *   如何正确使用 `if err != nil { return ..., err }` 模式。
    *   何时应该处理错误，何时应该向上返回。
    *   如何为用户提供有意义的错误信息。
    *   如何设计一个库的错误处理策略？（暴露哪些错误，包装哪些错误）。

## 9. 上下文 (Context)
*   **核心概念**：`context.Context` 用于在 API 边界之间传递截止时间、取消信号和请求作用域的值。
*   **关键原理**：Context 是并发安全的，通常作为函数第一个参数传递。`WithCancel`, `WithTimeout`, `WithDeadline`, `WithValue`。
*   **面试考点**：
    *   Context 的核心方法：`Done()`, `Err()`, `Deadline()`, `Value()`。
    *   Context 的典型使用场景（HTTP 请求处理、数据库操作）。
    *   常见陷阱：Context 存储值应仅限于请求范围的数据（如 trace ID），不要滥用。
    *   如何正确地传播和取消 Context？

## 10. 性能分析与优化 (pprof)
*   **核心概念**：Go 内置了性能分析工具 `pprof`，可以分析 CPU、内存、阻塞和锁竞争。
*   **关键原理**：通过 HTTP 端点或写入文件收集性能数据。使用 `go tool pprof` 进行可视化分析。
*   **面试考点**：
    *   如何启用 `net/http/pprof`。
    *   `cpu profile`, `heap profile`, `goroutine profile` 的作用。
    *   如何解读性能分析报告，定位性能瓶颈（如热点函数、内存分配点）。
    *   常见的性能优化手段（减少内存分配、使用对象池、优化并发结构）。

## 11. 泛型 (Generics)
*   **核心概念**：Go 1.18 引入泛型，允许编写类型参数化的函数和类型。
*   **关键原理**：类型参数（`[T any]`）、类型约束（`comparable`，自定义接口约束）、实例化。
*   **面试考点**：
    *   泛型函数和泛型类型的声明语法。
    *   类型约束的作用，尤其是 `comparable` 和 `~` 操作符的使用。
    *   泛型的优势（代码复用、类型安全）与潜在的性能影响。
    *   适用场景：通用数据结构（链表、栈、队列）、通用算法（排序、过滤）。
