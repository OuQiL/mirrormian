## Purpose

定义 mirror-mian 的复习规划能力：基于画像（薄弱点 + SM-2 状态 + 掌握度 + 到期复习项）生成行动化的复习计划——今日行动项、优先级与顺序、每项练习建议与预计耗时。

## ADDED Requirements

### Requirement: 复习计划生成

系统 SHALL 基于画像生成复习计划：输入画像数据，输出结构化计划——按优先级排序的行动项（到期复习/薄弱主题/掌握度低主题）、每项的建议练习方式与预计耗时。

#### Scenario: 生成计划

- **WHEN** 请求生成复习计划
- **THEN** 输出按优先级排序的行动项列表，每项含主题、建议练习方式、预计耗时与顺序建议

#### Scenario: 无数据时提示

- **WHEN** 画像为空（无薄弱点/掌握度/到期项）
- **THEN** 返回提示「先完成几场面试积累画像」，不报错

### Requirement: 计划入口

系统 SHALL 提供 `plan` 命令与 Web 复习页「生成复习计划」按钮，输出可读的复习计划。

#### Scenario: CLI 计划

- **WHEN** 执行 `plan` 命令
- **THEN** 打印复习计划（今日行动项 + 顺序 + 建议）

#### Scenario: Web 计划

- **WHEN** 在复习页点击「生成复习计划」
- **THEN** 页面展示复习计划内容
